# 路线图

## 已完成（v0.1.0）

- **核心层**：凭据解析、HTTP 与错误翻译、媒体处理、异步轮询、输出封装、成本记账
- **MiniMax H3**（V2 直连）：文生视频 / 首帧 / 尾帧 / 首尾帧 / 多模态参考
- **Seedance**（火山方舟直连）：文生 / 首帧 / 首尾帧 / 全模态参考 / 有声 / flex 离线档
- **通义万相 Wan**（百炼直连）：t2v / i2v / r2v / 参考生视频 / 反向提示词 / 多镜头
- 每家配一个**任务查询**节点，避免本地超时后重复提交重复计费
- 价格表外置（`core/prices.json`）+ 用量 JSONL 记账
- CI：Ruff + 语法编译 + 导入冒烟测试（用 stub 顶掉 ComfyUI 依赖）

## 计划中

### 图像类节点

三家都同时提供图像生成接口，统一接入到同一套 `core` 里：

| 厂商 | 模型 |
|---|---|
| MiniMax | （H3 生态暂无公开图像生成 API） |
| Seedance | 即梦系列走字节其他端点，需单独确认 |
| 通义万相 | `qwen-image` 系列、`wanx2.1-t2i` |

### 视频编辑类

- Seedance 2.x 的**延长视频 / 编辑视频 / 局部重绘**
- MiniMax 的 768P → 2K 再生成（`/v2/video_regeneration`）
- MiniMax 的 **Context-IR**（`/v2/h3_context_ir`）——把提示词结构化，官方称其"对最终输出质量至关重要"，
  本地跑没有这一步，是 API 画质更高的原因

### 工程化

- **批量节点**：读 JSON/CSV 分镜表，自动排队生成，按 `shot_xxx` 命名落盘
- **成本看板**：把 `usage.jsonl` 汇总成按天/按模型的花费表
- **Webhook 支持**：厂商支持 `callback_url` 时改为回调而非轮询
- **重试与幂等**：网络抖动重试，但不重复创建付费任务
- **素材上传助手**：给 Seedance / MiniMax 提供"本地文件 → 可公网访问 URL"的一键通道
  （目前只能手填 URL，是这两家最大的使用摩擦）

## 已知限制

- **节点未经真实 API 端到端验证**：开发环境没有各家的 Key。协议依据官方文档实现，
  CI 只做静态检查与导入冒烟测试。首次使用请用最便宜的档位跑一条（5 秒 / 最低分辨率）。
- **Seedance / MiniMax 的本地图片需要公网 URL**：这两家文档都只承诺公网 URL；
  万相明确支持内联 base64。目前项目对前两者会在退回内联时打印警告。
- **批量并发受限**：MiniMax 免费额度 2 个并发、付费 15 个；火山方舟按账号限流。
  批量务必串行。
- **价格表会过期**：`core/prices.json` 每个条目带 `checked` 日期，超过两三个月请复核。
